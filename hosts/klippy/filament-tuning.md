# Reference values

Temp tower:
- PLA:
  - Start: 210
  - End: 190

Flow ratio:
- Test type: YOLO
- Top surface patter: archimedian chords
- Requires brim or ears, they won't stick properly otherwise

PA tower:
- Extruder type: bowden
- Start PA: 0
- End PA: 0.5
- PA step: 0.05

Retraction tower:
- Start: 1mm
- End: 6mm
- Step: 0.2mm
